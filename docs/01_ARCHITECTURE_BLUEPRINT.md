# 系統架構藍圖規格書 (Architecture Blueprint)

## 1. 系統整體架構 (System Architecture)

本系統採輕量、高相容、零延遲的純前端 SPA (Single Page Application) 架構，配合非同步背景計算與高效能繪圖管線：

## 2. 模組職責劃分

1. **核心計算引擎 (Engine Core)**
   - 封裝於 `<script type="text/plain" id="engine">`。
   - 兼具 Web Worker 背景緒執行與主執行緒 `new Function()` 動畫生成雙重能力。
   - 負責執行重力計算 (`gravity`)、3 連消除判定 (`clearGroups`)、遞迴連鎖模擬 (`cascade`)、單步擴展 (`expand`) 與價值函數遞迴 (`vals`)。

2. **盤面與使用者互動 (UI View & Controller)**
   - 5x5 卡片視覺矩陣：支援以屬性筆刷點擊上色。
   - 運算熱度圖視覺化：依據期望消除數正規化處理，將最高分格子給予高飽和度與黃金光暈標記，低分格子淡化灰暗。
   - 模擬播放器 (Simulator)：點擊模擬按鈕即時演練消除及掉落動畫。

3. **影像視覺辨識 (Computer Vision)**
   - 支援直接貼上截圖 (Clipboard Paste)、拖曳 (Drag & Drop) 與檔案選擇。
   - 第一階段：自動尋找遊戲面板底色（HSV 藍色濾鏡）並分析連通區域與形態學侵蝕，尋找 5x5 格線。
   - 第二階段：若自動辨識誤差，提供可拖曳式多邊形覆蓋框，使用者可於手機觸控拖曳角點微調，即時更新盤面。

4. **資料持續化 (Persistence)**
   - 使用瀏覽器 `localStorage` 保存盤面與結果，頁面重整或手機瀏覽器縮放時自動復原。
