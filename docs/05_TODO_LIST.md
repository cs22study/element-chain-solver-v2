# 元素連鎖計算機 APP - 待辦事項與優先優化清單 (TODO List)

依據 5 大原則與使用者體驗分析，以下為後續各模組的建議規劃與優先級：

## 優先級圖例
- [P0] 核心 UX / 高頻操作關鍵改善（建議優先執行）
- [P1] 重要功能增強（顯著提升便利性）
- [P2] 體驗與進階功能（PWA、擴充分享）

---

### [P0] 模組 1：盤面編輯輔助與復原 (Undo / Clear / Reset)
- [ ] **歷史回溯機制 (Undo / Redo)**：點錯格子時可一鍵退回上一步，避免重畫整盤。
- [ ] **快速清盤/隨機測試盤 (Reset / Randomize)**：快速產生測試盤或全部重置為預設盤面。
- [ ] **滑動連續上色 (Drag-to-Paint)**：支援手指/滑鼠在盤面上滑過連續塗色，大幅減少點擊次數。

### [P0] 模組 2：截圖辨識穩健性與手動微調 UI 優化
- [ ] **點擊格子直接切換色塊**：截圖後若有 1~2 格辨識錯誤，可直接在畫面上點擊該格循環切換屬性，不用重新切換筆刷。
- [ ] **動態 HSV 閾值 / 容錯範圍調整**：改善在不同手機螢幕亮度或遊戲特效下的辨識率。
- [ ] **直接支援剪貼簿貼上按鈕**：手機瀏覽器貼上提示與快速按鈕。

### [P1] 模組 3：模擬動畫增強與逐步演練 (Step-by-Step Simulation)
- [ ] **逐步播放/暫停/重播控制器**：除了自動播放外，支援「下一步」手動逐步觀察每一輪消除與掉落細節。
- [ ] **連鎖消除張數與得分統計即時彈出數字 (Float Score UI)**。

### [P1] 模組 4：演算法效能與策略擴充
- [ ] **多執行緒 / SharedArrayBuffer 優化**：進一步加快 3 步與 4 步深度的計算速度。
- [ ] **自訂屬性權重**：神魔之塔特定關卡可能特定屬性掉落機率提高，提供自訂掉落權重介面。

### [P2] 模組 5：PWA 支援與離線快取
- [ ] **Web App Manifest (`manifest.json`)**：設定圖標與啟動畫面，支援「加入主畫面」。
- [ ] **Service Worker (`sw.js`)**：離線可用與快速載入快取。

### [P2] 模組 6：GAS 雲端分享與精選盤面儲存 (可選零花費模組)
- [ ] **串接 Google Apps Script 免費後端**：儲存高難度經典盤面、一鍵產出分享網址。
