### [P0] 模組 1：自由開局、盤面編輯輔助與復原 (已完成 ✅)
- [x] **自由開局按鈕 (🎲 自由開局)**：演算法生成符合遊戲真實情境之合法盤面（保證無初始 3 連消除）。
- [x] **重設與重填盤面 (🔄 重設盤面 / 🎨 單色重填)**：一鍵回到預設盤面，或以當前筆刷顏色填滿 25 格，方便從頭佈局。
- [x] **歷史回溯機制 (↩️ 復原 / ↪️ 重做)**：40 步歷史堆疊，支援單擊、連續劃刷、自由開局、截圖套用之復原；支援 `Ctrl+Z` / `Ctrl+Y`。
- [x] **滑動連續上色 (Drag-to-Paint)**：支援滑鼠與手機觸控滑動連續塗色（Pointer Events + setPointerCapture），單次劃刷合併為單一 Undo 步。
- [x] **右鍵快速切換屬性 (Right-Click Cycle)**：右鍵點擊單元格快速循環切換五屬性。
- [x] **自動化測試覆蓋**：`tests/solver.test.js`, `tests/engine.test.js`, `tests/html.test.js` 全數通過。
