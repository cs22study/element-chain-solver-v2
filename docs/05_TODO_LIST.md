### [P0] 模組 1：自由開局、盤面編輯輔助與復原 (已完成 ✅)

- [x] **重設與重填盤面 (🔄 重設盤面 / 🎨 單色重填)**：一鍵回到預設盤面，或以當前筆刷顏色填滿 25 格，方便從頭佈局。

- [x] **右鍵快速切換屬性 (Right-Click Cycle)**：右鍵點擊單元格快速循環切換五屬性。
- [x] **自動化測試覆蓋**：`tests/solver.test.js`, `tests/engine.test.js`, `tests/html.test.js` 全數通過。
