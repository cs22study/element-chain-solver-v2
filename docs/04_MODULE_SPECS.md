# 各模組開發細節規格書 (Module Specifications)

## 模組 1：自由開局、盤面重設與歷程回溯 (Board Setup, Reset & Undo/Redo)

### 1.1 需求背景
原作者專案在進入頁面後預設為固定範例盤面，若玩家想手動模擬一局新遊戲，缺乏快速產生合法盤面的功能；且在手動點選 25 個格子佈局時，若誤點顏色無法復原，必須手動逐一改回，且點選 25 次效率較低。

### 1.2 核心規格設計
1. **自由開局 (🎲 自由開局)**：
   - 函數：`generateRandomBoard(noInitialMatches = true)`
   - 演算法：自左上角 $(r, c) = (0, 0)$ 走訪至 $(4, 4)$，針對每個單元格，排除使其與上方兩相鄰格子成 3 連、或與左方兩相鄰格子成 3 連之同屬性顏色（至多排除 2 種屬性，保證至少有 3 種合法顏色可挑選，無死鎖風險）。
   - 確保盤面符合《神魔之塔》開局特性：**完全無初始 3 連消除**。
2. **重設盤面 (🔄 重設盤面)**：
   - 函數：`resetBoard()`
   - 一鍵還原至系統標準預設測試盤面（`DEFAULT_BOARD`）。
3. **單色重填 (🎨 單色重填)**：
   - 函數：`fillBoardWithBrush()`
   - 一鍵將 25 格全部塗滿為當前選取的筆刷顏色，方便玩家從乾淨畫布開始自訂佈圖。
4. **歷程回溯堆疊 (↩️ 復原 / ↪️ 重做)**：
   - 堆疊深度：上限 40 步（`MAX_HISTORY = 40`）。
   - 支援操作：單擊上色、連續滑動塗色、自由開局、重設、單色重填、套用截圖辨識。
   - 快速鍵支援：`Ctrl+Z` (Undo), `Ctrl+Y` / `Ctrl+Shift+Z` (Redo)。
5. **連續滑動塗色 (Drag-to-Paint)**：
   - 支援滑鼠拖曳與行動裝置觸控滑動：採用 `Pointer Events` 搭配 `setPointerCapture` 與 `document.elementFromPoint`。
   - 單次劃刷（Stroke）自動合併為單一 Undo 歷史節點，點一下 Undo 即可復原整條筆劃。
6. **右鍵快速循環切換 (Quick Right-Click Cycle)**：
   - 電腦版桌機操作時，右鍵點擊任一格子即可循環切換該格屬性（水 $\to$ 火 $\to$ 木 $\to$ 光 $\to$ 暗 $\to$ 水），無須切換筆刷。
